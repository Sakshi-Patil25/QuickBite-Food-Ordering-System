# QuickBite Food Ordering System

## Project Overview

QuickBite is a full-stack food ordering application developed using React, Spring Boot, and MySQL.

## Technologies Used

### Frontend
- React JS
- React Router
- Axios
- Context API

### Backend
- Spring Boot
- REST APIs

### Database
- MySQL

## Features

- User Login Interface
- Dynamic Food Menu
- Category Filtering
- Shopping Cart Management
- Order Placement
- Cart Persistence
- Admin Dashboard
- Food CRUD Operations
- MySQL Integration

## Admin Features

- Add Food
- Edit Food
- Delete Food

## Modules

- Home Module
- Menu Module
- Cart Module
- Order Module
- Admin Module

## How To Run

### Backend

```bash
mvn spring-boot:run
```

### Frontend

```bash
npm install
npm run dev
```
